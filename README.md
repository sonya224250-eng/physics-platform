# Физика • Учебная платформа

Платформа для учителя физики и учеников, готовая к публикации на **GitHub Pages** (`https://github.com/sonya224250-eng/physics-platform`).

## Возможности
- **Вкладки с уроками**: создание, редактирование и удаление уроков с поддержкой формул LaTeX (`$E = mc^2$`, `$$F = ma$$`).
- **Домашние задания**: публикация ДЗ внутри уроков, отправка решений учениками (текст + фото/PDF), проверка и выставление оценок с комментариями.
- **Конструктор тестов**: вопросы с выбором одного или нескольких вариантов ответа и задачи с числовым/кратким ответом (с автопроверкой).
- **Мои оценки**: ученики могут проверить свои оценки и комментарии учителя по имени и классу.
- **Светлая и тёмная тема**.

## Подключение Supabase (чтобы работало у всех учеников)
1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте бесплатный проект.
2. Откройте **SQL Editor** → **New query**, вставьте содержимое файла `supabase_setup.sql` и нажмите **Run**.
3. Откройте **Authentication** → **Users** → **Add user** → **Create new user** и создайте аккаунт учителя (email + пароль).
4. Откройте **Project Settings** → **API** и скопируйте **Project URL** и **anon public key** в файл `config.js`.
5. Загрузите файлы на GitHub и включите **Settings → Pages → Branch: main**.
